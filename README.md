# MC

A Minecraft addon project for Tensura: Reincarnated.

## Project status

The project is being planned. No mod code or build configuration has been added yet.

The proposed target is NeoForge on Minecraft 1.21.1 with Java 21, pending
confirmation that the selected Tensura release supports this version and loader.

## Development

Build and run instructions will be added once the compatible Tensura release and
development dependencies have been verified.
