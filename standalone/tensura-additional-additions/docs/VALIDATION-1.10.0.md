# 1.10.0 — The High Realm

Adds the independent `heavenlyrestriction:high_realm` dimension: scoped amplified density functions, three biomes, calcite/basalt surface rules and native-block ore features. The Overworld generator and other dimensions are not replaced. The default entry requirement is **10,000,000 actual maximum EP**, configurable server-side.

The 5 × 6 multiblock has two horizontal orientations and a clear 3 × 4 opening. It awakens once with one Nether Star, persists across restarts and supports individual return destinations. Entry verifies the complete frame and EP; foreign dimension-travel events also enforce EP. The return sanctum uses a bedrock threshold, quartz/amethyst structure and light pillars. It is protected from normal block edits/explosions and suppresses natural spawning within 48 blocks. Return travel has no EP check, finds safe ground and falls back to the Overworld spawn. Direct arrivals also initialize a return sanctum. Gates do not force-load their source chunks; particle emission is shared between nearby players. World Hop's fresh-seed path resets gate/return terrain data; saved-world revisits retain it.

A nine-type whitelist upgrades only naturally spawned, unowned ordinary mobs. Three archetypes retain native entity types/AI and receive native EP, HP, SHP, equipment and resistance skills. Bosses, summons, tamed/subordinate mobs and imports are excluded. Saved elites do not reapply upgrades, heal on reload or become persistent simply because of their names. Native kill EP is retained; elite rewards augment drops.

**226 native GameTests and 31 JVM tests passed** on Tensura 2.0.1.3 / NeoForge 21.1.209. The ten realm scenarios cover loaded generation/biomes, spawn pools, exact frame/air/fluid/corner validation, actual modified EP and foreign travel checks, gate/individual-return NBT round trips, obstructed/flooded/hazardous exits, elite identity/stats/skills, reload/despawn behavior, boss/owner/summon/import exclusion, natural spawn marking, sanctum spawn/explosion protection, native kill EP, arrows and loot. The opt-in GameTest preset includes the dimension because Minecraft's GameTestServer normally bakes only its hardcoded vanilla flat preset; that preset override is excluded from the distribution.

The real integrated client loaded the dimension into a copied **existing save** without the test preset. A real C2S use-on-block packet consumed exactly one Nether Star; charged walking entry preserved inventory and skills. Safe return worked below the EP requirement, another entry required no new star, and walking exit worked with zero EP. The final client run also exercised the searchable **Dimensions** page in the F8 guide at two GUI scales. Game screenshots of the gate, return sanctum, terrain and guide were visually reviewed. The fixture and reproduction steps are in [review-high-realm](review-high-realm/README.md).

The Tensura 2.0.1.4 / NeoForge 21.1.248 profile passed API compilation. This is compilation coverage rather than a new full Neo Otherworld pack runtime test. The baseline release is built separately; the distribution audit checks metadata, all realm data resources and exclusion of both review classes and the test-only world preset.
