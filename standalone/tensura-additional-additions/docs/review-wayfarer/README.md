# Kael Veyr client review

This opt-in fixture uses an existing disposable normal-generation save named **Wayfarer Review** in `/workspace/validation-wayfarer/client/saves`. Never point it at a personal save: it resets the review character and builds a combat stage in The High Realm.

```sh
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 ALSOFT_DRIVERS=null ./gradlew clean runClient -I docs/review-wayfarer/client.init.gradle
```

The fixture verifies 15,000,000 actual EP, the native otherworlder renderer, one HP boss bar and real damage to a native-race combat target. It checks native Magic Wind Transform, then activates native Wind Cutter, Tornado Blade, Aura Slash and Aerial Blade, and captures gameplay at 1280×720. PNGs and a pass/fail marker are written to `/workspace/validation-wayfarer/capture`.

Server regressions live in `docs/review-high-realm/KaelVeyrGameTests.java` and run with the existing High Realm GameTest profile:

```sh
./gradlew test runGameTestServer -I docs/review-high-realm/server.init.gradle
```

Clean before a production build. Neither review fixtures nor the test-only flat-world preset may be shipped; the distribution audit checks their exclusion.

## Native integration references

Implementation was checked against the pinned Tensura 2.0.1.3 classes `OtherworlderEntity`, `OtherworlderRenderer`, `HinataSakaguchiEntity`, `AuraSlashArt`, `MartialMasterSkill`, `WindDominationSkill`, `InfiniteRegenerationSkill`, `InstantRegenerationEffect`, `TornadoBladeMagic` and `AerialBladeMagic`, `LawManipulationSkill`, `MagicElementalTransformSkill`, `DivineKiReleaseSkill`, `EyeOfTruthSkill`, `UnpredictabilitySkill`, `EnergyHelper` and `DeathHandler.gainEPEntity`, plus Hinata's native entity-existence data. Kael uses native stored skill instances and preset slots, native magic release callbacks, resource costs, cooldowns, damage sources and seals. His renderer retains the native player-like equipment layers. The original player-UV skin and emissive mask are generated by `scripts/create-wayfarer-skin.py`; no third-party skin is redistributed.
