# 1.10.1 — High Realm enemies and magic

Replaces all six vanilla spawn types with ordinary Tensura creatures. Ten species now occupy the three existing biomes: Orc, Armorsaurus, Horned Bear, Lesser Daemon; Direwolf, Blade Tiger, Knight Spider; Lizardman, Basilisk, Greater Daemon. Terrain, the gate and the EP requirement are retained. Greater elemental spirit bosses are explicitly excluded alongside the existing boss guards.

Each species receives 9–10 mastered native skills, supplemented by retained native abilities. Toggles are enabled and Fighter/Berserker are placed in the active preset so their slot-dependent hooks function. Species packages include Berserker, Survivor, Fighter, Seer, native attack/armor/sense bonuses, poison/paralysis, resistances and Ultraspeed Regeneration. Regeneration uses native resources; there is no added Infinite Regeneration or blanket barrier layer.

Lesser Daemons receive the five magics used by their own combat brain: Fire, Water Cutter, Wind Cutter, Stone Shot and Fire Ball. Greater Daemons receive seven: Fire Lance, Acid Shell, Icicle Lance, Tornado Blade, Thunder Orb, Stone Shot and Sleep Mist. Their existing native casting behaviours, GeckoLib animations, magic circles, resource-cost pairs and projectiles perform the attacks. Mana and elemental Manipulation skills improve these attacks; the addon does not replace the daemon AI with scripted damage.

The realm-specific spawn handlers allow valid moss/calcite/basalt surfaces while retaining difficulty, darkness, world-border, fluid and native collision checks. This fixes native grass/sub-Y70/rareness conditions that would otherwise prevent the selected mobs from appearing as intended. Other dimensions and non-natural spawning retain their rules; explicit event failures from other mods are respected. An elite alert updates both vanilla target state and SmartBrain attack memory once per second, excluding owned/controlled mobs and creative/spectator/allied targets.

Saved eligible unowned Tensura elites get versioned loadout upgrades without resetting base EP or refilling resources. Repeating the upgrade does not stack modifiers. Old vanilla elites are retained until normal despawning, but no new ones spawn. New spawners work in existing generated chunks because biome definitions retain their IDs.

The native engine suite includes all existing integration scenarios plus the expanded realm coverage. New scenarios inspect all ten species for mastered/enabled skills and equipped Fighter, validate native daemon spell access, preserve current HP/SHP/aura/magicules through migration and prevent modifier replay/owned-mob changes. Surface tests exercise the old Lizardman restriction, blocked positions and unchanged Overworld checks. Autonomous daemon-brain probes observe actual magic-projectile spawn events and native casting circles with positive magicule costs; these are latched across ticks so instant hits and normal regeneration do not produce false negatives. A stronger-player alert scenario checks target memory, creative exclusion and ownership safety.

See [the audit](research/HIGH-REALM-LOADOUTS.md) for inspected native APIs and [the opt-in fixture](review-high-realm/README.md) for reproduction. **232 native GameTests and 31 JVM tests passed** on Tensura 2.0.1.3 / NeoForge 21.1.209. Autonomous combat was verified in the native engine.

The Tensura 2.0.1.4 / NeoForge 21.1.248 profile also passed API compilation. This is not a new full Neo Otherworld pack runtime test. The final release is built against the supported 2.0.1.3 baseline, with a package audit verifying the all-Tensura spawn pool, added classes/data, guide content and exclusion of review classes and the test-only world preset.
