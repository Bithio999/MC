# Additions 1.23.2 — Metis analysis and native magic impacts

Metis manual Analysis selects an eligible unowned skill without Great Sage's probability roll. Its original intrinsic/common/extra pool is extended to learned, permanent ResistSkill instances, including nullifications. Known skills, temporary skills and the native no-plundering tag remain excluded. Native plunder events and SkillHelper acquisition still decide whether a copy can be granted; the target keeps their skill. Living/projectile selection retains native ranges and visibility checks. There is no expansion to Unique or Ultimate copying.

Analysis writes only Metis mode 3's cooldown: 5 seconds normally, 2 seconds mastered, configurable in `tensura-additions-metis.toml`. Unavailable attempts have a 1-second retry delay. Pressing again during cooldown cannot shorten it or change Autonomous Sage's mode-1 state.

Analytical Appraisal uses configurable levels 20/40. Its native toggle, filtering and distance modifiers remain intact. Activation, mastery and respawn refresh the higher level through native AttributeHelper; periodic refresh also upgrades an existing active appraisal without stacking modifiers or requiring a retoggle. The native +15/+25 distance modifiers are additive to base appraisal distance.

Native Tensura magic projectiles now receive independent transient hurt windows keyed by caster, skill, mode and projectile UUID, whether cast manually or automatically. The existing paired-hit wrapper routes both components through the same projectile window. Independent projectiles therefore land full hits, while repeated pulses from one persistent projectile keep native cadence. Direct automatic spell provenance remains separate. Ordinary arrows, Battlewill projectiles and melee retain native windows; explicit native cooldown-bypass flags, resistances and defensive invulnerability remain native. Per-target storage is bounded at 64 entries and is not persisted.

The focused suite contains 21 native cases. New coverage checks guaranteed resistance/nullification copying with native copy chances forced to zero, retained source skills, cooldown isolation, learned/temporary/tier/protected filtering, projectile copying, native range, appraisal activation/mastery/respawn and non-stacking refresh. Real native Wind/Fire/Water projectile damage is exercised through TensuraProjectile.dealDamage: two distinct rapid projectiles deal 40/40, 30/30 and 40/40 with unmodified target defenses. Repeating one persistent projectile retains native 30/20/0 immediate-repeat behavior. Existing source-copy/reload, manual-state, defensive-invulnerability and automatic-casting cases remain in the suite.

Validation passed: **394 required native tests** on Tensura **2.0.1.3 / NeoForge 21.1.209**, **21 focused native tests** on **2.0.1.4 / 21.1.248**, and **64 JVM tests** in the final clean baseline production build. The second profile is an API/runtime compatibility check, not a full modpack playthrough. The distribution audit verified the 1.23.2 metadata, new analysis class, combat mixins, assets and absence of review fixtures or bundled dependencies.
