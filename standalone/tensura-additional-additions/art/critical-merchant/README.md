# Critical Merchant icon

Original generated pixel artwork: a grinning gold merchant mask in a burgundy hood, a ruby eye, critical-hit star and three-pip die. `source.png` preserves the authored source. Run `scripts/pack-critical-merchant-art.sh` from this addon directory to export the checked-in 64×64 RGBA icon with nearest sampling. Gradle consumes that icon without running image generation or ImageMagick.
