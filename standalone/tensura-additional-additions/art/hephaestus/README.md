# Hephaestus icon

Gold-framed hammer and anvil, with a molten strike on a dark cyan inset. The square frame, transparent corners and centered padding match native Tensura skill icons. The generated source is preserved here; export the runtime **32×32 RGBA** texture with `scripts/pack-hephaestus-art.sh`. Gradle uses the checked-in result without an image-generation or ImageMagick dependency.
