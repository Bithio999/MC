# Hephaestus icon

Original pixel emblem: steel hammer, black iron anvil, molten gold strike, copper laurel and a gold ring on dark plum. The source preserves the replacement for the earlier portrait concept. Export the runtime 64×64 RGBA icon with `scripts/pack-hephaestus-art.sh`; Gradle uses the checked-in output without an image-generation or ImageMagick dependency.
