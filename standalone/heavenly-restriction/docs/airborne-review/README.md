# Airborne dash and reincarnation panel review

Opt-in client fixture restricted to the isolated `Restriction Validation` save. Tests actual-player midair activation and native costs/cooldowns for Chained and Unbound; opens the native race selection and Ultimate menus for screenshots. Normal builds exclude this fixture.

```sh
gradle runClient -I docs/airborne-review/client.init.gradle
```
