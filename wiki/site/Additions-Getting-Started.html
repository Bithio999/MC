Getting started

TensuraAdditionalAdditions · Reference

Install Java 21, Minecraft 1.21.1 / NeoForge, Tensura 2.0.1.3–2.0.1.4 and its required libraries, plus GeckoLib 4.9.2+ (4.x). Add TensuraAdditionalAdditions 1.9.2 and remove older copies. Tensura Myths must not be installed alongside it.

For Heavenly Restriction, select Fettered Human at reincarnation; it starts with Chained. The lineage page lists evolution requirements.

The addon works with Tensura Neo Otherworld 1.1.3a. That pack’s Restricted Human is Mysticism’s separate race; choose Fettered Human for this addon’s lineage. Pack compatibility.

Press F8 for the in-game guide. Parallel World Jumper is private single-player only; the remaining content supports multiplayer when both client and server have the addon.
