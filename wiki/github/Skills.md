## Obtaining skills

Uniques join Tensura’s configured reincarnation primary pool. Rolls remain random. There are no skill trials or skills awarded for boss kills. Ultimates require Sovereign Hunter, two million base EP and mastery of the matching Unique.

## Using skills

Equip and cycle active modes using Tensura’s normal ability interface. Enable the passive with the native skill toggle in **Ability Selection**; it is separate from the active modes. It requires ongoing aura. `/wildhunt status` shows its on/off state and upkeep.

## Power

Mastery improves damage by up to 50%; Ultimates use a 3× base multiplier. Damage does not scale with EP. Read [Combat mechanics](https://github.com/Bithio999/MC/wiki/Mechanics) for damage types, barriers, and aura costs.

[Aion, God of Causality](https://github.com/Bithio999/MC/wiki/Aion) evolves from any mastered Myths Ultimate after True Hero or True Demon Lord awakening and 12M base EP. See [Godly Skills](https://github.com/Bithio999/MC/wiki/Godly) for classification, menu access and progression.
