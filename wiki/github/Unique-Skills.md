# Unique Skills

[All wikis](https://github.com/Bithio999/MC/wiki/Home) · [Tensura Myths](https://github.com/Bithio999/MC/wiki/Tensura-Myths)

Eight skills join Tensura’s reincarnation pool. Chained is granted separately by Fettered Human.

| Skill | Role |
| --- | --- |
| [Black Flame](https://github.com/Bithio999/MC/wiki/Black-Flame) | Black Flame is a Unique Skill inspired by Nu Udra. It uses visible oil tentacles to pull targets into burning ground. |
| [Frostbound Colossus](https://github.com/Bithio999/MC/wiki/Frostbound-Colossus) | Frostbound Colossus is a Unique Skill inspired by Jin Dahaad. It combines avalanche impacts, ice capture, and a defensive carapace. |
| [Mirrorbound](https://github.com/Bithio999/MC/wiki/Mirrorbound) | Mirrorbound is a Unique Skill focused on splitting light attacks and timed projectile reflection. |
| [Rune Smith](https://github.com/Bithio999/MC/wiki/Rune-Smith) | Rune Smith is a Unique Skill focused on armed proximity trap and remote demolition. |
| [Scarlet Deluge](https://github.com/Bithio999/MC/wiki/Scarlet-Deluge) | Scarlet Deluge is a Unique Skill inspired by Uth Duna. It combines travelling currents, aimed whirlpools, and native barriers. |
| [Storm Crown](https://github.com/Bithio999/MC/wiki/Storm-Crown) | Storm Crown is a Unique Skill inspired by Rey Dau. It combines ricochet lightning with an aimed movement art. |
| [Threadweaver](https://github.com/Bithio999/MC/wiki/Threadweaver) | Threadweaver is a Unique Skill focused on single-target leash and spatial severance. |
| [Verdant Keeper](https://github.com/Bithio999/MC/wiki/Verdant-Keeper) | Verdant Keeper is a Unique Skill focused on allied hp/shp support and forward root control. |
