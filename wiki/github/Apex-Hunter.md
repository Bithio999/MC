## Obtaining

Begin as Awakened Hunter. Reach 400,000 base EP and defeat 3 different eligible boss types. No trial, skill roll or skill mastery is required for this stage. [Boss eligibility and counting](https://github.com/Bithio999/MC/wiki/Evolution#distinct-boss-kills).

## Traits

| Attribute | Bonus at this stage |
| --- | ---: |
| Maximum health | +500 HP |
| Maximum spiritual health | +3,200 SHP |
| Attack damage | +4 |
| Movement speed | +10% |
| Knockback resistance | +0.2 |

These replace the previous hunter stage’s racial modifiers. They do not stack with earlier stages. Toggleable skill passives have separate modifiers and remain subject to attribute caps.

The HP bonuses across the branch are +100 / +500 / +1,000; SHP bonuses are +400 / +3,200 / +6,600. Each stage replaces the previous stage’s bonus.

## Racial Ability

**Damage type:** None — the race grants a recovery Extra Skill, not an elemental attack.

This stage grants **[Apex Renewal](https://github.com/Bithio999/MC/wiki/Apex-Renewal)** as a native Extra Skill, at no permanent magicule acquisition cost. Earlier recovery tiers remain learned, but only the strongest toggled tier heals. Native racial skill learning enables the new tier automatically.

Base energy uses two thirds aura and one third magicules. Default-alignment kill EP retains Tensura’s native 2:1 split.


Continue building a distinct-boss record toward the next stage. You can roll and use apex Unique skills before reaching this stage. Race evolution does not directly grant a Unique skill.
