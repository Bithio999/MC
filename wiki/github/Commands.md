# Commands

[All wikis](https://github.com/Bithio999/MC/wiki/Home) · [Tensura Myths](https://github.com/Bithio999/MC/wiki/Tensura-Myths)

Normal progression uses Tensura’s menus; these shortcuts are for operators/testing.

| Command | Purpose |
| --- | --- |
| `/mythsguide` | Open the in-game guide |
| `/myths boss summon` | Summon Ananke |
| `/myths boss arena` | Create Ananke’s native arena |
| `/bossFight join @s ananke` | Join that arena |
| `/summon wildhunt:alma` | Summon Alma |
| `/summon wildhunt:gemma` | Summon Gemma |

Boss pages explain survival-mode summoning. [Ananke](https://github.com/Bithio999/MC/wiki/Ananke) · [Eschaton](https://github.com/Bithio999/MC/wiki/Eschaton).
