# Getting started

[Main Page](https://github.com/Bithio999/MC/wiki/Home) · [Reference](https://github.com/Bithio999/MC/wiki/Mechanics) · [Ability index](https://github.com/Bithio999/MC/wiki/Abilities) · [Damage types](https://github.com/Bithio999/MC/wiki/Damage-Types)

This guide covers installing **Tensura Myths**, rolling an apex skill, and beginning the Human hunter evolution branch.

## Requirements

- Minecraft 1.21.1 and Java 21.
- NeoForge 21.1.209 or newer in the 21.1 line.
- Tensura: Reincarnated 2.0.1.3, ManasCore 4.0.0.2, Architectury and GeckoLib **4.9.3 (4.x)**, SmartBrainLib and TerraBlender.
- Tensura Myths 0.29.1 installed on both client and server.

## Installation

Download the 0.29.1 addon from the repository’s `releases` directory. Replace older Wild Hunt / Tensura Myths jars; do not load two versions together. The addon jar is not a complete modpack.

## First reincarnation

Complete Tensura’s ordinary reincarnation flow. All eight Myths Uniques are eligible starting rolls alongside the server’s configured pool. A particular apex skill is not guaranteed. Existing rolled skills remain valid after upgrading.

## First hunter evolution

Stay Human, grow to 100K base EP, and defeat one eligible boss type. Select Awakened Hunter in the evolution menu or use `/wildhunt evolve`. Race progression and skill rolling are independent.

## Choosing a playstyle

Choose [Storm Crown](https://github.com/Bithio999/MC/wiki/Storm-Crown) for ricochets and mobility, [Scarlet Deluge](https://github.com/Bithio999/MC/wiki/Scarlet-Deluge) for currents and native barriers, [Black Flame](https://github.com/Bithio999/MC/wiki/Black-Flame) for visible tentacle pulls and burning ground, or [Frostbound Colossus](https://github.com/Bithio999/MC/wiki/Frostbound-Colossus) for avalanche impacts and ice capture.

Each skill has a separate toggleable passive in Tensura’s Ability Selection. Toggle it on for sustained benefits while paying aura upkeep. Mastery improves damage; EP does not supply an addon damage multiplier.

## In-game help

`/wildhunt guide` explains progression. `/wildhunt status` shows base EP, distinct boss IDs, mastery and passive status. [Command reference](https://github.com/Bithio999/MC/wiki/Commands).


## Beyond the hunter path

Use Tensura’s **right-side Secondary Race / Convergent Awakening tabs** and **Skills → Godly → Ascension** menus for [Duo Races](https://github.com/Bithio999/MC/wiki/Duo-Races), [Convergent Awakening](https://github.com/Bithio999/MC/wiki/Convergent-Awakening), and [Godly Skills](https://github.com/Bithio999/MC/wiki/Godly). Use **Skills → Ultimate → Synthesis** for combination Ultimates. [Aion](https://github.com/Bithio999/MC/wiki/Aion), [Thoth](https://github.com/Bithio999/MC/wiki/Thoth) and [Lugh](https://github.com/Bithio999/MC/wiki/Lugh) each have four active arts and a separate toggleable passive, plus the three shared Godly classification passives.
