# TensuraAdditionalAdditions

[All wikis](https://github.com/Bithio999/MC/wiki/Home) · [TensuraAdditionalAdditions](https://github.com/Bithio999/MC/wiki/TensuraAdditionalAdditions)

A standalone addon for **Tensura: Reincarnated**, focused on Heavenly Restriction, Battlewills and world travel. Current release: **1.17.1** · Minecraft **1.21.1** · NeoForge.
