# Hunter’s Recovery

[All wikis](../README.md) · [TensuraAdditionalAdditions](TensuraAdditionalAdditions.md)

**Hunter’s Recovery** is an aura-powered Extra Skill granted by [Unshackled](Additions-Unshackled.md). It provides recovery inspired by native Self Regeneration.

| Skill data | Value |
| --- | --- |
| Type | Extra Skill |
| Damage type | None — healing / survival |
| Resource | Aura |
| Activation | Passive toggle |
| Race | [Unshackled](Additions-Unshackled.md) |
| Acquisition cost | No permanent magicule cost |

## Recovery

**Damage type: None.** Toggle through the skill menu. 4 HP each second, or 8 HP when mastered.

20 aura per HP. Full applicable health costs nothing. Recovery is limited to the available aura budget; HP receives priority over SHP.

Only the strongest enabled aura-recovery tier heals. Full health costs nothing; recovery is limited by available aura and normal healing suppression.
