# Apex Renewal

[All wikis](../README.md) · [TensuraAdditionalAdditions](TensuraAdditionalAdditions.md)

**Apex Renewal** is an aura-powered Extra Skill granted by [Heavenly Restricted](Additions-Heavenly-Restricted.md). It provides recovery inspired by native Ultraspeed Regeneration.

| Skill data | Value |
| --- | --- |
| Type | Extra Skill |
| Damage type | None — healing / survival |
| Resource | Aura |
| Activation | Passive toggle |
| Race | [Heavenly Restricted](Additions-Heavenly-Restricted.md) |
| Acquisition cost | No permanent magicule cost |

## Recovery

**Damage type: None.** Toggle through the skill menu. Missing HP every half second.

30 aura per HP, or 20 when mastered. Full applicable health costs nothing. Recovery is limited to the available aura budget; HP receives priority over SHP.

Only the strongest enabled aura-recovery tier heals. Full health costs nothing; recovery is limited by available aura and normal healing suppression.
