# Sovereign Rebirth

[All wikis](../README.md) · [TensuraAdditionalAdditions](TensuraAdditionalAdditions.md)

**Sovereign Rebirth** is an aura-powered Extra Skill granted by [Heavenbreaker](Additions-Heavenbreaker.md). It provides recovery inspired by native Infinite Regeneration.

| Skill data | Value |
| --- | --- |
| Type | Extra Skill |
| Damage type | None — healing / survival |
| Resource | Aura |
| Activation | Passive toggle |
| Race | [Heavenbreaker](Additions-Heavenbreaker.md) |
| Acquisition cost | No permanent magicule cost |

## Recovery

**Damage type: None.** Toggle through the skill menu. Missing HP and SHP every half second; funded protection against ordinary lethal HP damage.

30 aura per HP and 10 per SHP; 20 / 5 when mastered. Full applicable health costs nothing. Recovery is limited to the available aura budget; HP receives priority over SHP.

Only the strongest enabled aura-recovery tier heals. Full health costs nothing; recovery is limited by available aura and normal healing suppression.
