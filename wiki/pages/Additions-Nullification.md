# Nullification

[All wikis](../README.md) · [TensuraAdditionalAdditions](TensuraAdditionalAdditions.md)

**Nullification** is the unique engraving built into the **[Inverted Spear of Heaven](Additions-Inverted-Spear-of-Heaven.md)**. It is registered in Tensura's engraving classification and uses the normal enchantment component.

| Engraving data | Value |
| --- | --- |
| Maximum level | I |
| Supported item | Inverted Spear of Heaven |
| Equipment slot | Main hand |
| Damage type | None directly; accompanies the weapon's Physical hit |
| Debuff duration | **2 seconds / 40 ticks** |
| Debuff refresh | A new hit refreshes its duration |
| Source | Built into the spear; not added to random engraving rolls |

Attacks shatter barriers, clear skill status effects, and block the target’s skill activation for **2 seconds**. The weapon can attack **Spiritual Entities**. Held dash/Counter attacks carry its engraving effects.
