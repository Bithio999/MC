# Inverted Spear of Heaven

The transparent authoring master follows the user-supplied silhouette: two broad unequal blade prongs separated by an open slot, a silver crossguard, dark brown wrapped grip and gold ferrule/pommel loop. It was authored with image generation using the supplied reference, replacing the earlier three-pronged sprite.

Run `python3 scripts/prepare-heavenly-arsenal-art.py` from the repository root to export the 64×64 Minecraft sprite into both distributions. ImageMagick provides nearest-neighbor resizing and binary alpha for clean item extrusion. The master remains unchanged. The native handheld item model supplies the inventory, ground and held views.
